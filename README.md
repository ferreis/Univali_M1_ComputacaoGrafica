# Computacao Grafica

Trabalho universitario de Computacao Grafica desenvolvido em C++ com OpenGL e FreeGLUT.

## Requisitos

- Visual Studio 2019 ou superior
- Carga de trabalho **Desenvolvimento para Desktop com C++**
- Windows SDK instalado

A dependencia FreeGLUT esta incluida na pasta `ComputacaoGrafica/freeglut`.

## Como executar

1. Abra `ComputacaoGrafica.sln` no Visual Studio.
2. Selecione a configuracao `Debug` e a plataforma `x64`.
3. Compile e execute o projeto `ComputacaoGrafica`.

Os arquivos gerados pela compilacao ficam fora do controle de versao por meio do `.gitignore`.

## Controles

- Setas direcionais: movimentam o pentagono.
- Barra de espaco: aumenta a escala.
- `Esc`: encerra a aplicacao.
